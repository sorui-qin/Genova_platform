# Protein Context Preparation

The current contracts are preparation v2, component manifest v2, and Protein Context v4. Parameter definitions are governed by `backend.structure_contracts.PreparationOptions`. Only generation_auto_v1, supported_protein_v1, protein_metals_v1, and remove_all are accepted. Older protocols are neither upgraded nor executed.

Prepare the structure before selecting the site. Preparation retains the complete protein by default, supports selection of specific chains and the corresponding restriction of their nonprotein components, and does not require a docking box or reference ligand in advance. All water is removed. Removing components does not modify the source file. Preparation options separately control missing-atom completion, gap reporting, standardization of supported modifications, protonation, and restrained minimization. Selected components are retained in the complete prepared structure. The effective receptor retains protein and standalone metals; ligands, cofactors, sugars, nucleic acids, and water are removed from it while retaining their source mappings. By default, only the verified allowlisted MSE → MET conversion is automatic. SEP, TPO, PTR, SEC, and other modifications without a reliable parent mapping are retained by default. Covalent boundaries are restored only according to reliable rules: currently only CYS SG single-bond connections have a verified template. Other covalent modifications retain the original structure and connectivity and are documented explicitly; no bond cleavage or parameters are guessed. Valid submissions do not require a chemical precheck; diagnostics run in the background. Minimization is disabled by default.

After a preparation Job succeeds, define a site using the reusable prepared_receptor_id. One preparation can be used for multiple sites. The positioning reference and generation_reference are independent. The interface can preselect a nonmetal ligand automatically, and the user can adjust the selection. Metals are for positioning only; the default box size is 20×20×20 Å. An external generation reference must be a single-molecule 3D SDF, MOL, or MOL2 with coordinates aligned to the receptor. Verify the chemical definition, atom mapping, and coordinates of the source ligand.

In the Docking Box editor, “Reset to 20 Å” sets the three dimensions to 20 Å while retaining the current center. “Center on selection” recalculates both center and dimensions from the coordinates of the selected ligand or region so that the box covers that region.

Saving the Grid automatically builds and validates the required inputs for each model, recording compatibility as full, limited, incompatible, or unchecked. Generation uses only validated cached inputs and does not repeat protein preparation. If the cache is stale, save the Grid again to validate it. Only a v4 Context that passes checks of the current structure, parameters, provenance, file hashes, and specified model compatibility can be used for generation. A lack of docking preparation does not block generation. An archived Context is retained for historical traceability and is no longer used as input. Preparation and site saving do not constitute approval for molecular generation.
