# Inno-ADMET 模块介绍

Inno-ADMET模块主要用于系统的评价药物的吸收、分布、代谢、排泄和毒性性质，也包括一些理化性质和药物化学性质。系统提供了两个不同的模型来计算成药性性质，分别为基于预训练的MERT模型和基于GNN子结构可解释性的MGA模型。

基于自主收集的高质量数据，这两个模型均可实现17种物化性质、5种药物化学性质、6种成药性规则、21种ADME性质、27种毒性性质的系统性评价。从模型评估指标的角度来说，MERT模型更为优秀，根据模型能否提供子结构对预测结果的影响上判断，MGA模型更具优势，用户可根据自己的需要去选择相应的计算模型。

## 算法说明

### MERT (Pre-trained)
基于预训练Transformer模型的高精度ADMET预测方法。该模型通过大规模分子数据预训练，能够捕获分子的深层特征表示，在各种ADMET性质预测任务上表现出色。

**特点：**
- 高精度预测
- 基于Transformer架构
- 大规模预训练数据
- 快速推理

### MGA (Interpretability)
基于图神经网络的分子子结构可解释性模型。该模型不仅能够进行准确的ADMET预测，还能提供分子子结构对预测结果的贡献分析，帮助用户理解预测机制。

**特点：**
- 子结构可解释性
- 图神经网络架构
- 可视化分析
- 机制解释

## 预测属性分类

### 基础属性 (17个)
包括分子量、LogP、LogD、LogS、TPSA、QED、SAscore等基本物理化学性质。

### 吸收属性 (6个)
- **Caco-2**: 细胞透膜性
- **HIA**: 人体肠道吸收
- **Pgp-inh/sub**: P糖蛋白抑制剂/底物
- **F(20%/30%)**: 生物利用度

### 分布属性 (4个)
- **PPB**: 血浆蛋白结合率
- **VDss**: 稳态分布体积
- **BBB**: 血脑屏障通透性
- **Fu**: 游离分数

### 代谢属性 (21个)
涵盖各种CYP酶系的抑制和底物特性：
- CYP1A2, CYP2A6, CYP2B6, CYP2C8, CYP2C9
- CYP2C19, CYP2D6, CYP2E1, CYP3A4
- HLM/MLM/RLM 清除率和半衰期
- UGT底物特性

### 排泄属性 (2个)
- **CL**: 血浆清除率
- **T1/2**: 终末半衰期

### 毒性属性 (27个)
包括多个维度的毒性评估：
- **心脏毒性**: hERG
- **肝毒性**: DILI, Hepatotoxicity
- **遗传毒性**: Ames, Mutagenicity
- **致癌性**: Carcinogenicity
- **环境毒性**: 多种水生生物毒性指标
- **内分泌干扰**: 核受体和应激反应相关

## 使用建议

1. **选择合适的模型**：
   - 追求高精度：选择MERT模型
   - 需要可解释性：选择MGA模型

2. **输入数据格式**：
   - 支持SMILES字符串输入
   - 支持SDF/CSV文件上传
   - 支持分子绘制器输入
   - 支持数据中心选择

3. **结果解读**：
   - 注意各属性的最优范围
   - 关注Category类型属性的概率解释
   - 利用可解释性分析优化分子设计

## 技术特色

- **高质量数据**: 基于自主收集的高质量ADMET数据库
- **先进算法**: 结合预训练和图神经网络技术
- **全面覆盖**: 涵盖药物发现全流程的关键ADMET性质
- **易于使用**: 提供多种输入方式和直观的结果展示
- **可解释性**: MGA模型提供分子子结构贡献分析
