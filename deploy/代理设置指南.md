# Genova 代理设置指南

代理用于帮助平台连接 ChatGPT 和其他大模型服务。

如果你只使用平台，按第一部分操作。如果你负责安装和维护平台，先完成第二部分，再回到第一部分。

## 一、在平台中开启代理

### 1. 拿到代理地址

向平台管理员索取一条完整地址，例如：

```text
http://host.docker.internal:7897
```

其中 `7897` 是代理软件中显示的端口，也就是连接入口的编号。下文都以这个编号举例，填写时以实际设置为准。

### 2. 填写并保存

1. 登录 Genova，打开“设置”。
2. 找到“网络代理”。
3. 打开“开启代理”。
4. 在“代理地址”中粘贴管理员提供的完整地址，也可以从输入框的建议列表中选择。
5. 点击这一栏的“保存”。出现“代理设置已保存”后，继续下一步。

填写示例：

| 页面上的项目 | 操作或填写内容 |
| --- | --- |
| 开启代理 | 打开 |
| 代理地址 | `http://host.docker.internal:7897` |
| 保存 | 点击后等待“代理设置已保存” |

### 3. 检查大模型连接

1. 在同一页面找到“LLM 配置”，点击展开。
2. 选择要使用的配置。使用 ChatGPT 时，先完成页面上的 ChatGPT 授权，再选择模型。
3. 点击“读取模型能力”。页面显示模型能力，且没有红色错误提示，说明这一步已完成。
4. 点击“保存”，保存这份大模型配置。

需要进一步验证实际回答时，可以点击“测试连接”。这一步会发送一次模型请求，并使用相应的 API 或订阅额度。

代理设置保存在当前平台账户中。其他使用者需要在各自的账户里开启并保存。

## 二、管理员首次设置

需要完成两件事：让平台能够连接代理软件，再把这个地址加入平台的可选列表。

### 1. 准备代理软件

**使用 Clash Verge：**

1. 打开 Clash Verge，选择一条可用的代理线路。
2. 打开软件的“设置”，找到“端口设置”，记下“混合端口”的数字。
3. 开启“局域网连接”或“允许局域网连接”，让平台服务能够连接这个端口。
4. 保持代理软件运行。

首次安装和导入线路可参照 [Clash Verge 官方中文入门](https://www.clashverge.dev/guide/quickstart.html)。

**使用其他代理软件，例如 v2rayN：**

1. 打开软件，选择一条可用的代理线路。
2. 在软件设置或提供方说明中，找到供其他程序使用的 **HTTP 代理端口**或**混合端口**，记下数字。
3. 开启允许其他设备连接的设置；有的软件称为“允许来自局域网的连接”。
4. 保持代理软件运行。

Genova 的代理地址支持 `http://` 和 `https://`，使用无需填写用户名和密码的地址。如果软件只提供 `socks5://` 地址，需要先在该软件中开启 HTTP 或混合端口。

如果单位已经提供完整的 HTTP 或 HTTPS 代理地址，可以直接使用该地址。

### 2. 确定应该填写哪个地址

大模型请求由运行 Genova 服务的电脑发出。**代理地址要从这台电脑能够连接的位置来填写。**

| 平台和代理的位置 | 填写示例 |
| --- | --- |
| 代理软件与 Genova 服务在同一台电脑上，平台使用项目提供的 Docker 配置运行 | `http://host.docker.internal:7897` |
| 代理软件在同一局域网的另一台电脑上，地址为 `192.168.1.20` | `http://192.168.1.20:7897` |
| 单位或服务商已经提供完整代理地址 | 使用对方提供的地址 |

`host.docker.internal` 在这里表示运行 Genova 服务的电脑。平台在服务器上时，它指服务器；即使你从自己的笔记本打开网页，也应填写服务器能够连接的代理地址。

要查另一台电脑的局域网地址，可以在那台电脑的系统设置中打开“网络”，查看当前连接的 IPv4 地址。

### 3. 将地址加入平台配置

找到安装平台时使用的 `.env` 文件。文件名以 `.` 开头；在文件夹中看不到时，打开文件管理器的“显示隐藏文件”。

用文本编辑器打开，找到 `AGENT_PROXY_ALLOWED_URLS` 这一行，修改为：

```dotenv
AGENT_PROXY_ALLOWED_URLS=http://host.docker.internal:7897
```

如果没有这一行，就在文件末尾添加。把示例地址换成上一步确定的地址，然后保存文件。

有多个可选地址时，用英文逗号隔开：

```dotenv
AGENT_PROXY_ALLOWED_URLS=http://host.docker.internal:7897,http://192.168.1.20:7897
```

接下来让平台读取新设置。按自己的安装方式，执行下面对应的一条命令。

**使用本项目源码运行：** 编辑 `VERSE/.env`，在项目根目录打开终端，执行：

```bash
docker compose --env-file VERSE/.env -f VERSE/docker-compose.yml up -d --no-build --force-recreate --no-deps backend-api workflow-worker
```

**使用镜像发布包运行：** 编辑发布包中与 `compose.yml` 放在一起的 `.env`，在这个文件夹打开终端，执行：

```bash
docker compose --env-file .env -f compose.yml up -d --no-build --force-recreate --no-deps backend-api workflow-worker
```

如果安装时还使用了 `compose.chatgpt-local.yml`，则执行这一条：

```bash
docker compose --env-file .env -f compose.yml -f compose.chatgpt-local.yml up -d --no-build --force-recreate --no-deps backend-api workflow-worker
```

命令执行完成后，刷新 Genova 的“设置”页面。代理地址会出现在建议列表中。将完整地址发给使用者，让他们按第一部分开启代理。

## 三、修改、关闭和常见提示

**换代理线路：** 在代理软件中选择另一条线路。代理地址和端口保持相同时，Genova 中的地址继续沿用。

**换代理地址或端口：** 管理员先更新 `.env` 并执行上面的命令，使用者再到平台“网络代理”中填写新地址并保存。

**关闭代理：** 到平台“设置 → 网络代理”，关闭“开启代理”并点击“保存”。之后的大模型请求使用平台所在电脑的直接网络连接。

| 看到的提示或现象 | 下一步操作 |
| --- | --- |
| 部署管理员尚未允许代理地址 | 管理员按第二部分设置地址，然后使用者刷新页面。 |
| 此代理地址未获部署管理员允许 | 从建议列表中选择地址，或请管理员将要使用的地址加入配置。 |
| 请填写无认证的 HTTP(S) 代理地址 | 按 `http://地址:端口` 的形式填写；使用代理软件的 HTTP 或混合端口。 |
| 连接超时或无法连接 | 确认代理软件正在运行，核对端口数字和“允许局域网连接”设置；然后在代理软件中切换线路，再读取模型能力。 |
